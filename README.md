# Ahamed Shakir — Portfolio

A React portfolio implementing the "COCOA" Cleo-inspired design (warm cream + rich cocoa,
light/dark theme). Built with Vite.

**Live:** https://shakir-s-portfolio.vercel.app

## Develop

```bash
npm install
npm run dev      # start the dev server (http://localhost:5173)
npm run build    # production build → dist/
npm run preview  # preview the production build
```

## Structure

- `src/App.jsx` — composes every section in order.
- `src/components/` — one file per section (`Hero`, `Stats`, `About`, `Skills`, `Projects`,
  `Path`, `Certs`, `Mulearn`, `Languages`, `Contact`, `Footer`) plus `Nav`, `ToTop`, `CountUp`,
  `ImageSlot`, and `icons`.
- `src/hooks/` — `useTheme` (light/dark + localStorage), `useScrolled` (nav + back-to-top),
  `useReveal` (IntersectionObserver scroll reveals).
- `src/data.jsx` — all section content (nav links, projects, timeline, certs, languages, contact).
- `src/index.css` — the full design system (CSS variables, light/dark, responsive layout).
- `index.html` — `<head>` metadata: favicon, Open Graph / Twitter tags, fonts, no-flash theme script.
- `public/` — static assets served at the site root:
  - `favicon.svg`
  - `assets/` — project images (`proj-1…4.png`), the hero portrait (`Ahamed-Shakir-Photo.png`),
    the social-preview card (`og-image.png`), and the résumé / CV PDFs.

## Notes

- **Navigation** collapses into a hamburger menu below 860px (slide-down sheet, scroll-lock,
  Escape-to-close); the full link bar shows on wider screens.
- **Social previews:** Open Graph + Twitter `summary_large_image` tags point at
  `assets/og-image.png`. The card was generated by rasterizing an HTML template at 1200×630;
  regenerate it if the headline or branding changes.
- **Résumé / CV:** the hero has two download buttons → `assets/Ahamed-Shakir-Resume.pdf` and
  `assets/Ahamed-Shakir-CV.pdf`.
- Theme is applied before paint by an inline script in `index.html` to avoid a flash.
- Honors `prefers-reduced-motion` for reveals, counters, smooth scroll, and the mobile menu.
- Fonts: Unbounded (display), IBM Plex Sans (body), IBM Plex Mono (labels), loaded from Google Fonts.
